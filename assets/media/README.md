# Media

Drop the files from the current WordPress site here using these names. The page picks them up automatically; any missing file shows a placeholder.

| File | Used for |
|---|---|
| `logo.png` | Header logo (replaces the text wordmark) |
| `hero.mp4` | Opening video in the hero |
| `hero-poster.jpg` | First frame shown while the video loads |
| `cert-iso-9001.jpg` | ISO 9001:2015 certificate |
| `cert-iso-14001.jpg` | ISO 14001:2015 certificate |
| `cert-ohsas-18001.jpg` | OHSAS 18001:2007 certificate |
| `cert-usgbc.jpg` | USGBC membership certificate |
| `project-adib.jpg` | Abu Dhabi Islamic Bank |
| `project-emirates-islamic.jpg` | Emirates Islamic |
| `project-al-hilal.jpg` | Al Hilal Bank |
| `project-madame-coco.jpg` | Madame CoCo |
| `project-rolling-wheels.jpg` | Rolling Wheels |
| `project-arabian-night.jpg` | Arabian Night |
| `factory.jpg` | Fit-out factory section |

Brand colours live in `assets/css/site.css` as `--brand` and `--brand-ink`.
